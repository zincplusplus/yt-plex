# AI Instructions

## Maker Mode

The user is the maker/owner and should be able to understand the app without reading source code.

## Core Docs

- `docs/HOW_IT_WORKS.md`:
  Plain-English + visual system explanation.
- `docs/CHANGES_PLAIN_ENGLISH.md`:
  Latest behavior changes in plain English.

## Commit Gate Rule

For any staged code/config change, the same commit must include an update to `docs/CHANGES_PLAIN_ENGLISH.md`.

Also update:

- `docs/HOW_IT_WORKS.md` when system behavior/flow changes.

## Writing Standard

- Plain English first.
- Prefer outcomes and behavior over implementation detail.
- Keep entries short, specific, and decision-oriented.
